AI Usage Log — HealthHub

Milestone 1: Initial Setup, Static Frontend and Database Planning

AI Tool Used

ChatGPT was used occasionally for technical guidance and help during project development.

Areas of Assistance

* Clarifying project structure requirements.
* Getting suggestions for database entity relationships.
* Helping understand and troubleshoot code when problems occurred.
* Explaining technical errors and suggesting possible solutions.
* Troubleshooting a VS Code extension installation issue.

Examples of AI Limitations

1. A suggested VS Code extension installation method did not resolve the installation problem.
2. Some suggestions for solving technical problems did not work immediately, so additional checking and troubleshooting were needed.

Verification

The project files and changes are checked manually against the assignment requirements. AI suggestions are reviewed and tested before being used in the project.
